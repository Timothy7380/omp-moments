OMP Moments website
===================

Open index.html in a browser to view the site.

Files
- index.html        All the code: HTML, CSS (in <style>) and JavaScript (in <script>)
- assets/intro.mp4  Intro film (OMP reel)
- assets/logo.svg   OMP Moments signature logo (vector)
- assets/favicon.png, assets/avatar.jpg   Profile logo images
- assets/p/         252 archive photos: <id>_t.webp = thumbnail, <id>.webp = full size

To publish: upload the whole folder (index.html + assets) to any static web host
(Netlify, Vercel, GitHub Pages, cPanel, etc.). Keep the folder structure as is.
